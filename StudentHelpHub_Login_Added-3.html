Web Development

HTML Basics

HTML structures web pages using elements and tags.

Read notes

HTML (HyperText Markup Language) defines a webpage structure. Core tags: h1–h6 headings, p paragraphs, a links, img images, ul/ol lists, table tables, form forms, input fields and button controls. Example:

My College

Welcome!

. Use semantic tags such as header, nav, main, section and footer. Remember: most elements have opening and closing tags; img and input are void elements.

Web Development

CSS Basics

CSS controls colours, spacing, layout and typography.

Read notes

CSS (Cascading Style Sheets) styles HTML. Selectors: p targets tags, .card targets a class and #header targets an ID. Common properties include color, background, margin, padding, border, font-size and display. The box model contains content, padding, border and margin. Flexbox is useful for one-dimensional layouts; Grid is useful for rows and columns. Example: .card { padding: 16px; border-radius: 10px; }. Use media queries for responsive layouts.

Web Development

JavaScript Basics

JavaScript adds logic and interactivity to a webpage.

Read notes

JavaScript adds behaviour to webpages. Learn const and let, strings and numbers, arrays, if/else, loops and functions. Example: const add = (a,b) => a+b;. The DOM lets JavaScript read or change HTML elements. Event listeners react to clicks and form submissions. Validate user input, and never trust browser-side checks as security for a real server.

Programming

Python Basics

Python is a readable general-purpose programming language.

Read notes

Python uses indentation to define code blocks. Basic types include int, float, str and bool. Collections include list, tuple, set and dict. Example: for n in [1, 2, 3]: print(n). Use if/elif/else for decisions and def to create functions. Lists are ordered and mutable; tuples are ordered and immutable. Handle expected errors with try/except. Practise loops, functions and small programs.

Programming

C Programming Basics

C introduces structured programming and low-level concepts.

Read notes

A C program commonly includes #include and int main(void). Learn int, char, float and double, operators, printf/scanf, if/else, loops, arrays, strings and functions. Arrays store same-type elements in contiguous positions. A pointer stores a memory address; use pointers carefully. Example: int total = 0; for (int i=1; i<=5; i++) total += i;. End statements with semicolons and compile to catch errors.

Database

DBMS & SQL

A DBMS stores and manages structured data.

Read notes

A database is an organized collection of data. A DBMS helps create, read, update and manage it. A primary key uniquely identifies a row; a foreign key links tables. SQL examples: SELECT * FROM Students; INSERT INTO Students(id,name) VALUES (1,'Aman');

Database

Database Normalization

Normalization reduces unnecessary duplication in tables.

Read notes

Normalization organizes tables to reduce repeated data and insertion, update or deletion anomalies. 1NF requires each field to hold an atomic value and no repeating groups. 2NF removes partial dependency on part of a composite key. 3NF removes transitive dependency of non-key attributes. Use primary/foreign keys to model relationships, and draw an ER diagram before designing complex databases.

Networking

Computer Networks

Networks connect devices to share data and resources.

Read notes

Networks connect devices to exchange information. LAN covers a limited local area; WAN covers large geographic areas. OSI layers from bottom to top: Physical, Data Link, Network, Transport, Session, Presentation, Application. IP addresses identify network interfaces; DNS maps domain names to addresses. TCP provides reliable, ordered delivery; UDP has lower overhead but does not guarantee delivery. A router connects networks; a switch commonly connects devices within a LAN.

Computer Fundamentals

Operating System

An operating system manages hardware and application resources.

Read notes

An operating system manages processes, memory, files, devices, security and user interaction. Examples include Windows, Linux, macOS and Android. A process is a running program; scheduling shares CPU time. RAM holds active data, while virtual memory uses storage to support memory needs. File systems organize files and folders; permissions control access.

Computer Fundamentals

Computer Fundamentals

Computers process input into output using hardware and software.

Read notes

The information-processing cycle is input, processing, output and storage. Hardware includes CPU, RAM, storage and input/output devices. Software includes system software and applications. The CPU contains the control unit and arithmetic logic unit. RAM is volatile; SSD storage is non-volatile. Data units: 8 bits = 1 byte. Back up important files and use strong, unique passwords.

Computer Fundamentals

Computer Security Basics

Learn safe habits for accounts, devices and data.

Read notes

Use strong unique passwords and a password manager where possible. Turn on multi-factor authentication. Install updates, back up important files and download software from trusted sources. Phishing messages try to trick users into sharing information; verify unexpected requests through a separate trusted channel. Never share one-time codes or passwords.
